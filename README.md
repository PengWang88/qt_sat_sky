# SatSky - 卫星天空可视化系统

## 项目简介

SatSky是一个基于Qt框架开发的卫星天空可视化应用程序，用于实时显示和跟踪多卫星系统（GPS、BDS、Galileo、GLONASS）在极坐标图中的位置和运动轨迹。

## 功能特性

### 核心功能
- **极坐标可视化**：在极坐标图中显示卫星的方位角和仰角
- **多卫星系统支持**：支持GPS、BDS、Galileo、GLONASS等卫星系统
- **时间序列播放**：支持按历元时间步进播放卫星运动轨迹
- **轨迹显示**：可显示卫星的完整运动轨迹
- **卫星过滤**：支持按PRN号过滤显示特定卫星
- **数据导出**：支持将当前视图导出为图像

### 界面特性
- **直观的控制面板**：提供播放/暂停、前进/后退、跳转等控制功能
- **实时信息显示**：显示当前时间信息和卫星状态
- **卫星系统选择**：可选择性显示不同卫星系统的卫星
- **国旗图标显示**：根据卫星PRN显示对应国家的国旗图标

## 安装与构建

### 环境要求

- CMake 3.10+
- Qt 5.15+ 或 Qt 6.x
- C++17兼容的编译器
- Windows/Linux/macOS

### 构建步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd qt_sat_sky
   ```

2. **配置构建环境**
   ```bash
   mkdir build
   cd build
   cmake ..
   ```

3. **编译项目**
   ```bash
   cmake --build .
   # 或者使用make
   make -j$(nproc)
   ```

4. **运行应用程序**
   ```bash
   ./app/SatSky
   ```

## 数据格式说明

### AzEl数据文件格式

SatSky支持AzEl格式的卫星数据文件，格式要求：

```
时间戳 PRN 方位角(度) 仰角(度)
```

示例：
```
1700000000.0 G01 45.6 30.2
1700000000.0 C01 120.3 25.8
1700000060.0 G01 46.1 29.9
1700000060.0 C01 121.0 25.5
```

### 卫星PRN命名规则

- **GPS**：G01-G32
- **北斗(BDS)**：C01-C37  
- **Galileo**：E01-E36
- **GLONASS**：R01-R24

## 使用说明

### 基本操作

1. **加载数据文件**：程序启动后会自动加载AzEl数据文件
2. **时间控制**：
   - 使用"上一历元"和"下一历元"按钮手动步进
   - 使用"播放/暂停"按钮自动播放时间序列
   - 使用"跳转到历元"功能快速定位到指定时间
3. **卫星系统选择**：通过复选框选择要显示的卫星系统
4. **轨迹显示**：点击"显示轨迹"按钮显示卫星运动轨迹
5. **卫星过滤**：在过滤框中输入PRN号，点击过滤按钮显示特定卫星

### 界面布局

- **左侧**：极坐标绘图区域，显示卫星位置和轨迹
- **右侧**：控制面板，包含所有操作控件
- **顶部**：菜单栏和状态信息显示

## 开发指南

### 核心类说明

#### nova::AzEl
位于`src/utils/azel.h`，负责解析AzEl数据文件：
- `getTimeList()`：获取时间戳列表
- `getSatelliteData()`：获取指定时间的卫星数据
- `getSatellitePRNs()`：获取所有卫星PRN列表

#### SatSky
位于`ui/widgets/satsky.h`，主窗口类：
- 管理界面布局和用户交互
- 协调数据加载和显示
- 处理时间序列播放逻辑

#### PolarPlotWidget
位于`ui/widgets/polarplotwidget.h`，极坐标绘图控件：
- 绘制极坐标网格
- 显示卫星点和轨迹
- 支持自定义颜色和图标

### 扩展开发

#### 添加新的卫星系统
1. 在`SatSky`类中添加对应的显示标志
2. 在`getFlagByPRN()`方法中添加PRN识别逻辑
3. 在界面中添加对应的复选框

#### 自定义绘图样式
修改`PolarPlotWidget`中的绘图方法：
- `drawPolarGrid()`：修改极坐标网格样式
- `drawSatellitePoints()`：修改卫星点显示样式
- `drawTrajectoryPoints()`：修改轨迹显示样式
